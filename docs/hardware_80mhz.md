# 80 MHz DCS 硬件约束

## 已确认参数

| 环节 | 参数 | 配置值 |
|---|---:|---:|
| 双梳 | 重复频率 | 80 MHz（用户提供） |
| ATS9371 | 同步模拟通道 | 2 |
| ATS9371 | 分辨率 / 实际配置采样率 | 12 bit / 500 MS/s |
| ATS9371 | 硬件最高采样率 | 1 GS/s |
| ATS9371 | 模拟输入 | DC 耦合、50 Ω、±400 mV |
| ATS9371 | 模拟带宽 / ADC 奈奎斯特频率 | 1 GHz / 500 MHz |
| ATS9371 | 板载内存 | 8 GB |
| ATS9371 | 记录约束 | 最少 256 点、128 点对齐 |
| UHSM-I-10.6 | RF 输出带宽（50 Ω） | 300 Hz--≥700 MHz |
| UHSM-I-10.6 | 10.6 µm 电压响应度（50 Ω） | ≥700 V/W |
| UHSM-I-10.6 | 光谱范围（10% 点） | ≤3.0--12.5±0.3 µm |
| UHSM-I-10.6 | 输出 / 供电 | SMA / +9 V |

ATS9371 的理想量化步长按 0.8 V 满量程除以 4096 计算，约为
195.3 µV/LSB。实际噪声、有效位数和数据码型应以板卡校准与当前 ATS-SDK 为准。

## 为什么 RF 上限不是 500 MHz

在常用 500 MS/s 采样率下，采集卡的 250 MHz 奈奎斯特频率和探头的 ≥700 MHz 带宽都高于本系统的双梳
映射限制。对于实值探测且采用单一线性 RF→光学映射，本实现要求 RF comb 位于
`0--f_rep/2`，因此 80 MHz 重复频率对应 40 MHz 上限。配置使用 39 MHz 留出
滤波与边界余量。

## 7.5--11.5 µm 覆盖条件

目标光学带宽为：

```text
B_opt = c * (1 / 7.5 µm - 1 / 11.5 µm) ≈ 13.90 THz
```

一阶无混叠条件近似为：

```text
B_opt <= f_rep^2 / (2 * Delta f_rep)
```

代入 `f_rep = 80 MHz` 得 `Delta f_rep <= 约 230 Hz`。在 500 MS/s 下，一个
interferogram 周期约含 217 万个采样点；按 ATS9371 的 128 点边界向上对齐为
至少 2,172,416 点。若实际 `Delta f_rep` 更大，不能仅凭
700 MHz 探头和 1 GHz 模拟带宽恢复整段光谱，需要光学滤波、分段采集或改变
双梳参数。

## 上机前仍需实测

1. `Delta f_rep` 及其漂移；
2. 一个 IGM 的分段长度和中心 burst 位置；
3. 绝对波数锚点、RF 方向和四路 CW beat-note 中心频率；
4. ATS9371 原始 12 bit 码在当前 SDK 缓冲区中的对齐和电压换算；
5. 探头输出峰值，确保在 50 Ω 终端下不超过 ±400 mV 输入范围。

对应模板为 `configs/user_80mhz_ats9371_uhsm.toml`。可运行
`dcs inspect-config --config <配置文件>` 查看由当前参数推导出的限制和缺失校准项。
